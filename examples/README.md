# Example sessions — SYNTHETIC DATA

Every folder here is **synthetic**. The files were generated by `cardio-synth` (`CardioKit/Sources/SyntheticData`); none is a measurement. Each `metadata.json` has `"isSynthetic": true` and a `syntheticDescription` explaining the scenario.

They serve as:

- a sample of the CSV and metadata export format the app writes (identical writer code);
- inputs for `analysis/analyze_session.py`;
- ground truth (`truth_beats.csv`) for checking detection algorithms.

They have no gyroscope or audio files. Regenerate them with:

```sh
swift run --package-path CardioKit cardio-synth examples/synthetic
```

| Folder | Scenario |
|---|---|
| `SYNTHETIC-regular` | Regular 90 beats/min, no respiratory modulation |
| `SYNTHETIC-respiratorySinusArrhythmia` | 75 beats/min, ±18 % interval modulation at 15 breaths/min |
| `SYNTHETIC-prematureAndMissingBeats` | Two premature beats with compensatory pauses; three very weak beats |
| `SYNTHETIC-motionArtifacts` | Three large motion bursts |
| `SYNTHETIC-lowSNR` | Cardiac vibration buried in broadband noise |
| `SYNTHETIC-doublePeaks` | Second mechanical component nearly as strong as the first |
| `SYNTHETIC-jitterAndDroppedSamples` | 2 ms timestamp jitter, 3 % random drops, two 150 ms gaps |
